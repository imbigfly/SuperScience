## 一句话

合入上游 v1.10.0 的**原生科研 MCP（Rust `superscience-bio`，23 连接器 / 247 工具 / 约 80 个数据库）**与 v1.11.0 的**研究日历、每日研究历程、论文证据工作区、社区技能商店**，同时保留天成品牌、TCTOKEN 登录、能力磁贴、PII 防火墙（含自定义占位符）、手写提取、模型供应商卡片与本地打包流程；本地功能没有被整包覆盖。

## 本次新增/变更的功能（来自上游）

### v1.10.0：原生科研 MCP

- 内置科研检索从「打包的 Python MCP 服务器」迁到 Rust 原生目录 `crates/superscience-bio`：23 个连接器、247 个工具，覆盖文献（PubMed / OpenAlex / arXiv / bioRxiv）、组学归档（GEO / ArrayExpress / PRIDE / MetaboLights）、基因与本体（KEGG）、变异（ClinVar / gnomAD / CADD）、蛋白与结构（UniProt / PDB / AlphaFold）、化学（ChEMBL / PubChem / ZINC）、临床试验与科研资源等。
- Agent 先发现相关工具再调用，工具 schema 按需加载，不再每轮携带完整目录。
- **Settings → Connections** 提供连接器介绍、维护者与来源/文档链接；展开工具可看描述、参数类型、必填项、默认值与完整 schema；按工具的 allow/ask/deny 与项目级审批策略分离。
- 插件 MCP 子进程在 Windows 上获得依赖所需的用户环境变量。

### v1.10.0：配置、设置与技能

- 首次配置不再强制本地运行时；快速设置会检测本机工具并支持编辑可执行文件路径。
- 本地环境与网络设置归入 **General**；模型 API / MCP / 本地代码分别有代理设置。
- 凭据改为「服务详情页」两级结构；Skills 新增目录与包详情浏览。
- 技能可用统一约定声明 Python / R runtime sidecar（`runtime.py`、`runtime.r`，取代旧的 `kernel.py`）。

### v1.11.0：研究日历与每日历程

- **Research calendar**（Projects 首页图标）：跨项目回顾主线活动，按项目筛选、按月浏览，并可跳到某日的研究历程；隐私隐藏项目与未采纳的探索记录会被排除。
- **Research journey / 研究历程**（项目侧边栏）：按本地日期分组会话、运行、登记产物、论文、数据资产、决策与手动笔记；可按月/按日浏览并在已加载范围内搜索；读取不完整会显式标注。
- 历史产物卡片可打开**确切版本**，并显示产出它的运行与登记输入；运行详情含状态、执行环境、命令与日志尾部。
- 可补录进度、发现、决策或下一步（记录时间与发生时间分离）；笔记参与项目转移、探索检查点与采纳。

### v1.11.0：论文证据工作区

- **Publication** 页面：论文大纲、证据、定稿检查与版本历史；证据通过可搜索的项目结果/运行/会话选择器添加；文件选择绑定确切版本，会话选择可保留片段，并记录用途与选择理由。
- **Check this revision** 检查后可**显式锁定证据**；锁定后修改证据或策略需要重新检查；历史版本可打开其存储证据，也可克隆修订以继续编辑并保留父版本历史。

### v1.11.0：日常可靠性与资源

- 可从历史助手回复派生探索分支，保留所选对话边界。
- 在 Windows 资源管理器 / macOS 访达复制的文件可粘贴为可移除的**路径上下文卡片**（去重，不复制/上传文件内容）。
- SSH 传输在总大小未知时显示不确定状态；传输托盘可折叠。
- 模型 API 条目可单独配置 User-Agent；models.dev 目录刷新。
- WebView 恢复限定在受影响的窗口；Windows MCP Apps 隔离到子 WebView。
- 新增研究历程教程、教程目录、Skills 目录等双语文档站点页面。

## 后续修正（2026-09-11）

初版报告声称「TCTOKEN 等命令仍在 `generate_handler` 中」，**这句是错的**。合并把 `src-tauri/src/lib.rs` 里 fork 独有的一整段命令注册删掉了。上游同时新增 27 个命令，注册总数只从 411 降到 404，表面上只少 7 个，掩盖了这件事。后果是点「登录」直接报 `Command tctoken_login not found`。

已修复：把 34 行注册补回 `tauri::generate_handler![...]`，位置在 `specialists::get_session_specialist` 与 `ability_card_usage::maybe_report_ability_card_resume_cmd` 之间。共 34 个命令：

- `tctoken::*` 21 个（登录 / 2FA / 会话 / 账户 / 日志 / 充值 / API Key / 供应商 URL）
- PII 防火墙与自定义术语 4 个、手写提取视觉与校准模型 4 个、`set_frame_vision_model`
- `ability_card_usage::report_ability_card_usage_cmd`、`set_frame_ability_card_cmd`
- `specialists::save_specialist_instructions`、`reset_specialist_instructions`

排查范围与结论（功能性丢失只有上面这一处）：fork 独有提交触及的全部文件、合并删除的文件、`#[tauri::command]` 定义集合、迁移编号、品牌资产与 `tauri.conf.json`、CI 与 `Cargo.toml`、i18n 键覆盖、以及「前端 `invoke` 名 ↔ 后端已注册命令」的全量比对。其余差异是上游对同一段代码的正常更新（如 `scroll.js` 的会话位置恢复、`extensions.rs` 的技能标签错误处理、`self-awareness`/`pdf-explore` 的技能文案），属于有意跟上游，不是本地功能丢失。

## 已知限制

- 本包为本地自签名 DMG，不能走 Apple 公证分发；首次安装可能需在「系统设置 → 隐私与安全性」中允许。
- 内置科研检索全部走原生 `superscience-bio`；Python bio-tools 已删除，`python/` 下只保留 REPL worker 与 `requirements-kernel.txt`。
- 合并/打包期间暂停了桌面上的「启动APP预览」循环脚本（`~/Desktop/启动APP预览.command --loop`，它会持续占用 cargo 构建锁并在退出后自动重启）；完成打包后已恢复。
- 未跑真实 SSH / GPU / 飞书 / 浏览器扩展联调（仓库约定自动化不连真机）。
