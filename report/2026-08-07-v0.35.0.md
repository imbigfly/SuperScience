# SuperScience 更新报告 · v0.35.0

- **日期**：2026-08-07
- **版本**：0.35.0
- **来源**：合并上游 `xuzhougeng/wisp-science` (`upstream/main`) → 本地 fork `imbigfly/SuperScience`（`local/superscience`）
- **本地产物**：`target/aarch64-apple-darwin/release/bundle/dmg/SuperScience_0.35.0_aarch64.dmg`（`SuperScience Local Codesign`）

## 一句话

本版聚焦**会话连续性与交互体验**：可恢复最近工作区会话、导入会话归档、回复后追问建议与人工审阅；并增强文档阅读、上下文可见性与 Windows 发布签名。

## 核心功能更新

### 1. 会话连续性

- 启动时可恢复工作区最近的会话，中断对话可接续。
- 支持将会话归档（session archive）导入当前项目；导入映射持久化，重复导入会快进已有 frame 而非重复建会话。
- API 失败或会话恢复后，用户已发送的消息保持可见，不再丢失。

### 2. 回复与审阅交互

- 回复完成后自动建议追问问题，可一键继续深入。
- 回复新增人工审阅操作；审阅期间阻止继续发送，避免会话混乱。
- 中途插入的消息（cut-in）在交互中被正确保留。
- 反馈会话需用户确认后才开始，且会话可见。

### 3. 文档与上下文

- 新增 **anydoc** 富文档解析，可读更多文档格式。
- 图片工具增强（`image` crate）：过大图片缩放前增加确认。
- 自动上下文压缩增加过程动画，压缩时机与进度可见。
- 上下文用量仪表跟随会话当前模型实时更新。
- 聊天面板支持文件夹上下文；运行感知的状态宠物同步展示运行状态。

### 4. 界面与个性化

- 命令面板新增界面字号命令；聊天正文跟随字号设置。
- 凭证配置引导更清晰。
- 项目手动同步入口从「通用设置」移至「远程访问」设置。
- 环境面板可正确挂接会话服务器；模型切换弹窗清理与布局修复。
- 运行弹窗加宽；自动运行卡片锚定到对应轮次。

### 5. Windows 与发布

- Windows 安装包（MSI / NSIS）通过 **SignPath** 正式签名；CI 增加防误发测试签名包的保护。
- Windows 启动延迟优化，更快进入可用状态。
- 新增 AI 辅助问题报告；流式工具输出增加上限保护。

### 6. 稳定性与协议修复

- 修复 Responses / Anthropic 协议下未配对工具调用的清理问题。
- 达到 `max_iter` 时给出明确错误；复用会话 Agent 时正确应用 `max_iter`。
- 修复本地运行在启动超时后的重新挂接。
- 启动路径改为：**先扫描**孤儿 scratch，再在 deferred startup 中异步清理，并延后 publication / method-search / run 恢复，缩短首屏阻塞。

## 本地 fork 适配说明

合并上游后为本仓库做了品牌与工程对齐：

- crate / 产品名保持 `superscience-*` / `SuperScience`，bundle id `science.superscience`
- 补齐上游新增依赖：`image`、`anydoc`（`superscience-tools`）

- Skill frontmatter 的 `wisp:` 键保留（serde 兼容）
