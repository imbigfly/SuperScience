## 本次新增/变更的功能

### 上游 v1.4.0：SSH 任务闭环与可丢弃服务器

- SSH 任务可按 glob 收集输出、校验 checksum，大目录可打包取回，超大或需远端驻留的结果登记为远端引用。
- 已完成任务提供「结果与清理」：浏览、选择性下载/删除，并安全清理远端工作目录。
- 每个项目可为每台服务器设置远端数据目录、任务工作目录和本地结果目录；可选保留期限回收成功/失败任务残留。
- 登记暂存输入、上传文件和远端驻留结果；删除服务器前审计远端引用，放弃的产物标记为「来源已丢弃」。
- 传输尽量续传、回收日志、重试瞬时失败、清理孤立远端文件。
- Files 面板可将本地文件直接上传到当前浏览的 SSH 文件夹。
- 定时自动化：应用运行中向现有或新会话发周期性任务，重启后可补跑。
- 智能体配置工具：用户确认后做受约束的类型化设置变更。
- 模型档案支持逐模型 API 协议；自定义主题 CSS、外观设置与会话滚动位置恢复。

### 上游 v1.5.0：分享、生图/生视频、运行时隔离

- `/share`、顶栏分享和输入框 `+` 菜单可将会话导出为 PNG 长图或独立 HTML（可勾选回合、打码关键词）。
- 新增 Grok Imagine 图片与视频生成，结果 MP4 可在对话中播放。
- Python / R 运行时按会话隔离，并行会话不再共享变量或互相覆盖文件。
- 主页项目卡片可直接打开项目设置（含重命名），不必先进入项目。
- 浏览器离线横幅按回合判断；跨版本升级时旧键缺失不再把仓库打坏。

- 合入后大量残留 `wisp_*` crate 名已改回 `superscience_*`，否则 UI / Tauri 都编不过。
