## 本次新增/变更的功能

### 设置 · 专家

- 内置 / 自定义专家列表复用已有专家卡片（头像、角色、材料/技能/SOP 指标、开聊、删除），不再用手写扁平行。

### 设置 · 频道接入

- 列表页底部重新显示「加入同步项目」，**默认折叠**；展开后可粘贴设备码并加入。
- 飞书 / 微信 / StickS3 子页不显示该入口。
- Escape 只收起这一层，设置页仍开。
- 中继 URL / token 等「手动项目同步」后端表单仍然隐藏。

### 对话

- 运行监控工具名识别收成一处：`monitor_run` 与 `superscience_monitor_run`。
