# 天成科研助手 更新报告 · v1.0.0（本地增量打包）

- **日期**：2026-08-12
- **版本**：1.0.0
- **来源**：本地 fork `imbigfly/SuperScience`（`local/brand-tiancheng`），在已合入上游 v1.0.0 基础上继续增量开发后重新打包
- **本地产物**：`target/aarch64-apple-darwin/release/bundle/dmg/天成科研助手_1.0.0_aarch64.dmg`（`SuperScience Local Codesign`）

## 一句话

本版在 1.0.0 品牌基线上新增 **TCTOKEN 登录与用户中心**（侧栏入口 + 账户/任务/充值记录/API 密钥），并补齐 AI 画图能力卡与示例项目只读体验等本地改动。

## 本次新增/变更的功能

### 1. TCTOKEN 登录与「我的中心」

- 侧栏「设置」下方新增登录 / 用户信息入口。
- Overlay 支持用户名密码登录与 2FA；已登录后提供四页：
  - **账户**：余额、在线充值、兑换码、退出登录
  - **任务**：用量日志筛选与统计
  - **充值记录**：在线支付订单列表
  - **API 密钥**：复制密钥、「设为画图密钥」（写入当前图片生成模型 API Key）
- Token 存 Secret（`tctoken_access_token`）；额度按 `500000 ≈ $1` 换算为 `¥x.xx` 展示。
- Base URL 固定 `https://www.tctoken.cn`。

### 2. AI 画图能力入口

- 能力发现页在 AI 画图分组下增加机制图 / 可编辑图 / 生信排版等占位能力卡（入口展示）。

### 3. 示例项目与体验

- 示例项目（demo mode）允许查看资源与预览，仅限制发送/新建等写操作。
- 主题日/夜切换与去掉 Beta 角标等界面调整随本包一并带出。

## 重要稳定性

- 用户中心加载 effect 避免在回写 session 时形成无限请求循环。
- Playwright mock 覆盖登录态与四 Tab 基本渲染。

## 本地 fork 特有适配

- 品牌：`天成科研助手` / `science.superscience`

- 不包含外部按次扣费接口（`/billing/consume`）与可配置 Base URL
