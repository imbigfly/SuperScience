# SuperScience 更新报告 · v0.36.0

- **日期**：2026-08-09
- **版本**：0.36.0
- **来源**：合并上游 `xuzhougeng/wisp-science` (`upstream/main`，含 `v0.36.0` 及后续修复) → 本地 fork `imbigfly/SuperScience`（`local/superscience`）
- **本地产物**：`target/aarch64-apple-darwin/release/bundle/dmg/SuperScience_0.36.0_aarch64.dmg`（`SuperScience Local Codesign`）

## 一句话

本版聚焦**长会话可发现性与响应速度**：侧边栏会话搜索、空会话即时展示、大型工具结果限流；并带来探索分支、工作流按模型绑定、图像重复审计技能与更可靠的停止/等待状态。

## 核心功能更新

### 1. 会话导航与长会话性能

- 侧边栏支持项目级会话标题搜索，可找到尚未加载到当前分页的历史会话；清空搜索或按 Escape 恢复分组视图。
- 新建会话在发送第一条消息前即显示为「未命名会话」，与侧边栏历史同步。
- 限制桌面端工具结果、参数与终端输出的展示体积，避免对大型表格、FASTA、笔记本做深拷贝；大型科学会话完成、重开与继续时更流畅。
- 上下文错误在恢复后保持可见；模型切换确认布局更紧凑。

### 2. Agent 状态与任务控制

- 停止操作可中断等待响应、停滞的 SSE 流与重试延迟；停止失败时恢复操作入口并提示。
- 工具执行完成、正在等待模型回复时显示独立状态文案，与仍在运行的工具区分。
- 使用量统计中 SKILL / MCP 工具调用按模型占用排序，便于识别上下文开销。

### 3. 工作流模型选择

- 新增只读 `search_models` 工具，可按视觉、推理等能力发现已配置模型及其上下文、输出上限与凭证状态。
- `create_workflow` 支持通过 `model_id` 为任务节点绑定特定模型。
- Workflow Studio 高级执行控件补充预算留空即不限额说明，并改进输出 JSON Schema 提示。

### 4. 探索分支（Exploration）

- 支持在隔离工作区快照中创建、推进、丢弃探索分支，并可安全恢复历史轮次状态。
- 配套 store 迁移（exploration / project state revisions）与 UI 管理入口。

### 5. 科学技能与使用体验

- 新增「图像重复审计」技能及确定性脚本，检查论文图版中的重复、复用与疑似问题区域。
- 已完成的服务器传输卡片可自动收起；运行卡片支持手动关闭已完成项。
- 新增基础配置教程（模型、凭证、ACP、MCP、SSH、技能、项目导入导出等）。
- 修复文献研究快捷操作、侧边栏证据检索、工作区切换器、生成产物归因与 IME 标点选择器等问题。
- 前端载荷与 transcript 变更进一步限流；移除项目落地页 Beta 标签与无用 Tauri/preview 代码。

## 本地 fork 适配说明

合并上游后为本仓库做了品牌与工程对齐：

- crate / 产品名保持 `superscience-*` / `SuperScience`，bundle id `science.superscience`
- 上游 `crates/wisp-store/` 新增文件落到 `crates/superscience-store/`（含 exploration / project_state_revisions）
- 工作区目录 `.superscience/`；history URI 写入 `superscience-history:`，读取兼容 `wisp-history:`
- 环境变量优先 `SUPERSCIENCE_*`，兼容旧 `WISP_*`（部分路径仍以 `WISP_*` 为主，后续可统一）
- 本地 macOS 打包仍用 `scripts/package-macos-local.sh` + `SuperScience Local Codesign`
