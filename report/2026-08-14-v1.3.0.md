# SuperScience 更新报告 · v1.3.0

- **日期**：2026-08-14
- **版本**：1.3.0
- **来源**：合并上游 `xuzhougeng/wisp-science`（`upstream/main`，tag `v1.3.0`）→ 本地 fork `local/brand-tiancheng`
- **本地分支**：`local/brand-tiancheng`

## 一句话

本版聚焦**长会话与模型体验**：动态上下文用量、自适应压缩、内置斜杠命令与 `/share`，并修复合流超时、重复压缩和 MCP 进程树退出。

## 本次新增/变更的功能

### 长上下文、记忆与压缩

- 自动压缩改为按实际上下文增长选择目标，避免刚过阈值就反复压缩。
- 上下文用量改为动态仪表，明细更清楚。
- 设置页可直接把新习惯写入全局记忆。
- 新增真实长上下文记忆评估示例（约 68.5 万估算 token）。

### 模型与推理

- 内置 models.dev 目录，按精确模型 ID 提供上下文/输出上限（禁止前缀/家族模糊匹配）。
- 模型选择器支持按模型调整推理强度。
- 新建 DeepSeek 配置默认 `deepseek-v4-flash`。

### 智能体与命令

- 输入 `/` 时展示内置斜杠命令（含 `/plan`、`/permission`、`/share` 等）。
- `/share` 可将对话导出为可打码的 PNG。
- 达到最大迭代次数时生成回合摘要，不再突然结束。
- 流内上游错误展示具体信息；空的 `attempt_completion` 不再无结果结束回合。
- 编辑消息时，排队中的追问会回到输入框。

### 计算环境与浏览器

- 可设置默认分析执行环境（SSH/WSL 等）。
- 浏览器自动化支持持久化的 URL 拦截/偏好列表。

### 稳定性与界面

- HTTP 客户端改为连接/读超时，长流式回合不再被总 5 分钟超时掐断。
- MCP stdio 退出时清理完整进程树，取消路径更稳。
- 修复瞬时 API 回合中断、发送后残留追问建议、会话大纲开合动画等问题。

## 重要 bugfix 与稳定性改动

- 重复自动压缩：按增长量留自适应余量，失败后抑制无效重试。
- MCP 子进程树：初始化失败、drop、取消请求都会收掉 wrapper 与孙进程。
- Windows API 回合瞬时中断修复。
