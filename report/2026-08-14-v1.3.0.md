# 天成科研助手 更新报告 · v1.3.0

- **日期**：2026-08-14
- **版本**：1.3.0
- **来源**：上游 `xuzhougeng/wisp-science` v1.3.0 已合入 `local/brand-tiancheng`（`312344fc`）；本包再带上本地登录、附件粘贴、文本知识图谱与学术技能包
- **本地产物**：`target/aarch64-apple-darwin/release/bundle/dmg/天成科研助手_1.3.0_aarch64.dmg`（`SuperScience Local Codesign`）

## 一句话

合入上游 **v1.3.0**（长上下文用量、模型目录上限、推理强度），并补齐天成侧：首页登录入口、对话粘贴文件当附件、统计分析里的文本知识图谱，以及学术 / Nature / Office 技能包。

## 本次新增/变更的功能

### 上游 v1.3.0

- 长上下文记忆评估与动态上下文用量仪表；自动压缩按实际增长选目标，避免反复压缩。
- models.dev 目录随应用内置，按精确模型 ID 提供上下文 / 输出上限。
- 模型选择器支持逐模型推理强度；新建 DeepSeek 默认 `deepseek-v4-flash`。
- `/` 命令选择器展示内置斜杠命令；达到最大迭代时给出回合摘要。
- 设置页可直接把新习惯写入全局记忆。

### 首页登录与个人中心

- 首页顶栏「新建项目」右侧增加登录入口（首页会隐藏侧栏，必须另放入口）。
- 已登录显示头像首字母与名称，点击打开个人中心（TCTOKEN：账户 / 任务 / 充值 / API 密钥）。

### 对话附件

- 从访达 / 资源管理器复制文件再粘贴，会作为附件上传，而不只插入文件名。
- 图片仍可按剪贴板图处理；其它文件保留原名。提示改为「拖放或粘贴文件可附加」。

### 统计分析 · 文本知识图谱

- 首页「统计分析」新增 **文本知识图谱**（`knowledge-graph`）。
- 从论文或笔记抽出主谓宾三元组，本地标准库脚本生成可交互 HTML。
- 抽取用当前对话模型，不另配 API Key；与项目「研究图谱」不是同一功能。

### 技能与中文种子

- 内置学术写作 / 审稿、Nature 系列、OfficeCLI、Playwright、中文去 AI 味等技能包。
- ESR1 演示种子补充中文 i18n。

### 隐私

- 出站 PII 防火墙：邮箱 / 手机 / 证件号等先脱敏再发给模型，回复后再还原。

## 重要 bugfix 与稳定性

- 预设模型表单改为走 models.dev 目录查询填上限，不再调用已删除的硬编码函数。
- 解开 `Cargo.lock` 中 `reqwest` 的合并冲突，工作区可重新编译。
- 合入上游后残留的 `wisp_store` / `wisp_core` / `wisp_llm` 引用改回 `superscience_*`，否则 release 打不开包。
- 密钥继续只写本地 `secrets.json`，不进 SQLite。
