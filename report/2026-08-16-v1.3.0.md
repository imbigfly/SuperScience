## 本次新增/变更的功能

### 按最新文档对齐检查更新

- 查询仍是 `GET /api/client/update/check`，无需登录。
- macOS 传 `arch=m`（Apple Silicon）或 `arch=intel`；Windows / Linux 仍是 `arm64` / `x64`。
- 响应不再保证带 `has_update`：字段缺失时用 `latest > current` 判断；服务端明确 `has_update: false` 则不提示。
- 本地 semver 防降级保留；`force_update` 不会逼你装更旧的包。
- 「下载更新」和「打开下载页」仍会再打一次接口，用最新 `download_url`。

### 天成更新通道（本包仍包含）

- 检查、下载、打开下载页都走天成 Open API，不再读 GitHub Releases / Tauri 签名更新器。
- 默认基址 `https://www.tctoken.cn`，可用 `TCTOKEN_API_BASE` 覆盖。
- 按 `download_url` 流式下载，有 SHA-256 就校验，再用系统打开安装包。

## 重要 bugfix 与稳定性

- 若线上不再返回 `has_update`，旧逻辑会当成 `false` 从而永远不弹更新；本包已修。
- 空 `download_url` 时不展示「打开下载页」。
