# 天成科研助手 更新报告 · v1.2.0

- **日期**：2026-08-13
- **版本**：1.2.0
- **来源**：合并上游 `xuzhougeng/wisp-science`（`upstream/main` tip `f2270398`，含 `v1.1.0` 与 `v1.2.0`）→ 本地 fork `imbigfly/SuperScience`（`local/brand-tiancheng`）
- **本地产物**：`target/aarch64-apple-darwin/release/bundle/dmg/天成科研助手_1.2.0_aarch64.dmg`（`SuperScience Local Codesign`）

## 一句话

合入上游 **v1.1.0 + v1.2.0**：探索分支隔离与汇合、查询感知项目记忆、会话规则热重载；本地保留天成品牌、TCTOKEN 用户中心、频道接入卡片与对话内路径点击预览。

## 本次新增/变更的功能

### 上游 v1.1.0（此前未合入）

- 探索分支比较与汇合：对比分支结论并合并回主线；已合并分支冻结并保留回退语义。
- 经确认的智能体记忆；项目感知的会话搜索；命令面板升级。
- 外观可自定义字体族；项目卡片显示工作区路径；图标统一到共享 SVG 集。
- 长会话卸载旧行以节省内存；工作区快照增量且可取消。

### 上游 v1.2.0

- 探索工作流恢复相互隔离，状态不再串扰其他会话；已完成检查点不会被重复复用。
- 项目记忆检索升级为查询感知（query-aware）；会话可检测项目规则变更并热重载，需用户确认后才生效。
- 插件视图遇到无法解析的技能时降级显示；ACP 委派消息分块不再丢失。
- 会话级推理强度与模型配置档案统一；侧栏会话状态改为图标。
- 产物位置显示为工作区路径；内置 bio-tools 不再写入 `__pycache__`。
- 上游新增 Linux 安装包（本 fork 仍打 macOS 本地签名 DMG）。

### 本地 fork 一并带出

- TCTOKEN 登录与「我的中心」（账户 / 任务 / 充值记录 / API 密钥）。
- 设置「频道接入」卡片网格；隐藏手动项目同步表单。
- 对话正文中带路径的反引号文件名可点击，打开与产物卡片相同的预览。
- 密钥默认写入本地 `secrets.json`；日/夜主题切换。

## 重要 bugfix 与稳定性

- 探索期间非来源主线会话改为只读项目工具，避免误改冻结工作区。
- 空的 `attempt_completion` 不再结束回合；流式 SSE 错误会展示上游细节。
- 中文聊天与输入框跟随界面字号设置。
- 设置中可直接新增全局习惯。

## 本地 fork 特有适配

- 品牌：`天成科研助手` / `science.superscience`，版本升至 **1.2.0**
- crate 路径继续使用 `superscience_*`（上游 `wisp_*` 已改名合入）
- 打包：`scripts/package-macos-local.sh` + `SuperScience Local Codesign`
- 依赖：`reqwest` 启用 `cookies`（TCTOKEN 2FA session）
- 未在本机启用上游 Linux/arm64 的 wasm `reference-types` 关闭项（会破坏 macOS Trunk 打包）
