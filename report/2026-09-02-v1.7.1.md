## 一句话

本包修好启动窗口「先铺满、再缩回、再铺满」：最大化只在创建窗口时设一次。

## 本次新增/变更的功能

### 启动默认最大化（只设一次）

- 打开应用后主窗口铺满当前屏幕（保留标题栏，不是 macOS 独占全屏）。
- 只在窗口构建时使用 `.maximized(true)`。创建后和页面加载完成都不再调用 `maximize()`。
- 原因：macOS 上 `maximize()` 是绿色按钮那套缩放切换。上次在创建后、页面加载后再各调一次，再叠加不可靠的 `is_maximized()` 判断，就会先铺满、切回 1100×760、再铺满。
- 1100×760 只作为点绿色按钮还原时的尺寸。

### 能力卡片始终新开对话

- 当前会话正在流式输出时，再点首页或能力页的任意能力卡，会新建一条对话并启动该能力。
- 正在跑的旧对话会先缓存下来，不会被新开场气泡盖掉，后台继续跑。

### 模型页隐藏入口

- 「快速配置」和「添加 API 接入」默认隐藏。
- 在「模型 API 代理」输入框连续按 8 次空格后临时显示；离开模型页后重新隐藏。

### 首页与手写提取文案

- 顶栏按钮「随手一聊」改为「开始对话」。
- 手写数据提取：提示弹窗与进入对话的开场气泡都说明「发送图片同时对每列数据进行格式说明，识别率会显著提高」。
- 去掉开场回复里的 `view_image` / 出口防火墙隐私提醒（来自技能说明，不是界面文案）。

### 能力卡片用量上报

- 点击任意能力卡片并成功触发动作时上报 1 次；聊天类卡片在新建会话成功后上报（与点击合并，不双计）。
- 当日首次切回已有「能力对话」再上报 1 次（同会话同天仅 1 次）。
- `card_id` 使用现有能力卡片 id（如 `handwriting-extract`）；`card_name` 固定上报中文标题。
- 首页「科研主任」合成项 `research-director`；ComingSoon / PII 防火墙开关亦计入。

## 重要 bugfix 与稳定性改动

- 启动不再二次/三次调用 `maximize()`，避免窗口尺寸来回跳。
- 能力卡启动不再被「当前会话正在回复」拦住，与「新对话」及后端并行会话一致。
- 用量上报失败（含 API 未上线、网络错误）只打日志，不阻塞 UI。
- 未登录跳过上报，能力照常可用。
- 手写识图/校准不再把模型名和 API Key 传反（401 Invalid token）。
