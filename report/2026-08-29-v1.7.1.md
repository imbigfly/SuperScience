## 一句话

基于当前工作区重新打出 Apple Silicon 本地签名 DMG，主要加入本机 WeKnora 知识库检索，并修正「准备本机环境」不再每次启动都弹。

## 本次新增/变更的功能

### 知识库（WeKnora）

- 设置 → 能力 →「知识库」：选择提供方（第一期仅 WeKnora）、API 地址、密钥、默认知识库 ID、返回条数；可测试连接后保存。
- 首页 / 设置-能力共用一张「知识库」卡，点击进入该设置页。
- 对话只读 tool `knowledge_search`：只向 WeKnora 要检索片段，由本机 Agent 引用作答；不接 MCP，不接 `/knowledge-chat`。
- 密钥进本机凭据库，不进 SQLite，也不进 `CREDENTIALS` / `service_env`。
- 地址只填到 `http://localhost:8080` 时自动补 `/api/v1`。配置完整（地址 + Key + 默认库 ID）才注册 tool。

### 本机环境准备

- 欢迎流程结束后不再因旧字段 `show` 每次启动都弹出准备面板。
- 状态字段改为 `first_run`：仅首次引导后自动弹一次；之后只在点「配置本机环境」能力卡时打开。

### 设置 → 用量

- 「模型占比」与「工作区」并排等高，「SKILL / MCP 调用排行」单独满宽。

## 重要 bugfix 与稳定性

- 修了挡住 `src-tauri` 测试编译的旧 crate 名：`acp.rs` 测试里的 `wisp_acp` 改为 `superscience_acp`（协议字符串未改）。
