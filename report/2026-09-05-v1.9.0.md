# 天成科研助手 上游同步报告 · v1.9.0

- **日期**：2026-09-05
- **版本**：v1.9.0（从本地 v1.7.1 合入上游 `v1.8.0` + `v1.8.1` + `v1.9.0`）
- **上游来源**：`upstream` / `xuzhougeng/wisp-science` 分支 `main`（`15637a7e` Release v1.9.0）
- **本地分支**：`local/brand-tiancheng`
- **本地产物**：`target/aarch64-apple-darwin/release/bundle/dmg/天成科研助手_1.9.0_aarch64.dmg`（约 58MB，`SuperScience Local Codesign`，签名时间 2026-09-06 00:06）

## 一句话

合入上游 v1.8.0–v1.9.0 的 Python/R 工作台、工作区会话恢复、多窗口项目隔离与共享浏览器人工验证，同时保留天成品牌、TCTOKEN 登录、能力磁贴、PII 防火墙、手写提取与本地打包加速。本地功能没有被整包覆盖。

## 本次新增/变更的功能

### 上游 v1.8.0 Python & R Runtime 工作台

- 类似 RStudio 的四象限：源码编辑、多行控制台、变量检查、绘图面板
- Ctrl/⌘+Enter 跑选区或完整语句；Ctrl/⌘+Shift+Enter 在已绑定持久 Runtime 里跑整份脚本
- 智能体 Python/R 工具可用项目内 `script_path`，复用内存中的大对象
- 同一 Base URL 下不同模型可保存不同 API Key；对话可开 Fast 模式（priority service tier）
- Files 面板可按名称/大小/修改时间排序；聊天里右键项目路径可打开或在 Finder 中显示

### 上游 v1.8.1 工作区恢复与可靠性

- **导入项目 → 从工作区恢复会话**：扫描孤立文件夹的 `.wisp/history`，导入到 `Recovered` 而不改源归档
- 会话里保存的模型被删后会重新绑定，不再发送即中止
- 空转检测改为「连续相同工具循环」才中断，减少误杀
- 项目相对 `read` 从当前项目根解析；WSL Runtime 用 `wsl.exe --cd` 保留 Windows 路径
- 浏览器扩展更新横幅与受管扩展自动重载（扩展版本 0.3.1）
- CLI：`WISP_MAX_TOKENS` / `WISP_MAX_ITER` / `WISP_REASONING_EFFORT` / `WISP_VISION`

### 上游 v1.9.0 多窗口

- **文件 → 新建窗口** 打开空白项目首页，不继承当前工作区；未绑定项目不再 panic
- 每个窗口记住自己上次的项目；实时回复、审批、浏览器清理留在所属项目
- 审批范围/跳过审批可按项目覆盖；模型与全局设置仍共享
- 桌面换项目不再改飞书/微信 IM 目标
- 共享 Chrome 占用贯穿整个活动回合；验证码弹出人工验证并保留标签页
- 新对话快照当时的全局默认分析环境，之后改全局不影响已有对话
- ACP 配置按会话持久化；失败时明确「未回退 HTTP」

### 有意跟上游（本地行为会变）

- 产品版本 1.7.1 → **1.9.0**
- Run/SSH/harvest 从 `src-tauri` 抽到 crate `superscience-runs`（目录暂为 `crates/wisp-runs`，包名已是 fork 名）
- 远程默认数据根继续用 `~/superscience/...`，不是上游的 `~/wisp/...`
- 窗口模型改为「每窗口一个活动项目」：本地 `demo_save` / `skill_update` / scratch 已改走 `require_active(label)`，空白新窗口不再误用主窗口项目
- 审批策略按项目 overlay：工具确认跟着当前项目走
- 浏览器扩展显示名仍为 SuperScience Real Browser Bridge，版本跟上游 **0.3.1**
- 模型配置多了 `service_tier`（Fast 模式）

### 没有削弱的本地入口

- 登录、能力卡、手写提取、PII、反馈发信、TCTOKEN 更新检查文案均在 `generate_handler` 中
- 未加入 `tauri-plugin-updater`；应用内更新仍走 TCTOKEN
