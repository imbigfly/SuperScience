# 天成科研助手 更新报告 · v1.0.0

- **日期**：2026-08-10
- **版本**：1.0.0
- **来源**：合并上游 `xuzhougeng/wisp-science` (`upstream/main` tip `6a5e43a5`，含 `v1.0.0`) → 本地 fork `imbigfly/SuperScience`（`local/brand-tiancheng`）
- **本地产物**：`target/aarch64-apple-darwin/release/bundle/dmg/天成科研助手_1.0.0_aarch64.dmg`（`SuperScience Local Codesign`）

## 一句话

上游正式发布 **v1.0.0**：项目导入改为就地打开、传输非阻塞、会话检索与探索快照增强，并加入证据治理类研究技能；本地保留「天成科研助手」品牌与能力发现首页。

## 核心功能更新

### 1. 项目打开与传输

- 支持就地打开项目文件夹（in-place import），无需总是复制进工作区。
- 项目导入/导出改为非阻塞，大项目传输时界面可继续操作。
- 示例项目可设为只读查看。

### 2. 会话与探索

- 项目级会话搜索可发现尚未分页加载的历史会话。
- 工作区快照改为增量且可取消；探索期间冻结主线，避免误改。
- 网络中断等场景下，被打断的回合不再被误标为已完成。

### 3. 文件与界面

- Files 面板支持复制工作区路径。
- 侧栏行操作改为悬停显示；运行中才显示状态点。
- Composer / Tab / 产物卡片视觉收敛；中文「等待模型」文案更清晰。
- Windows 宠物状态标签裁剪问题修复。

### 4. 技能与发布

- 新增证据治理类研究工作流技能（evidence-governed research）。
- Zenodo DOI 更新；官方发版准备 `v1.0.0`。
