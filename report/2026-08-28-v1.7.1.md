# 天成科研助手 上游同步报告 · v1.7.1

- **日期**：2026-08-28
- **版本**：v1.7.1（从本地 v1.5.0 合入上游 `v1.7.1`，含 Browse + Trace & Trust + Remote Trust）
- **上游来源**：`upstream` / `xuzhougeng/wisp-science` 标签 `v1.7.1`
- **本地分支**：`local/brand-tiancheng`
- **本地产物**：`target/aarch64-apple-darwin/release/bundle/dmg/天成科研助手_1.7.1_aarch64.dmg`（约 54MB，`SuperScience Local Codesign`，签名时间 2026-08-28 17:21）

## 一句话

合入上游 v1.6.0–v1.7.1 的浏览器自动化、轨迹检查/导出、MCP 钥匙串、远程审批与运行时归因，同时保留天成品牌、TCTOKEN 登录、首页能力磁贴、浮层外置、本机环境准备和托管 R/officecli。本地功能没有被整包覆盖。

## 本次新增/变更的功能

### 上游 v1.6.0 Browse

- 真实 Chrome：共享会话 / 工作区配置、文章扫描、哈希取回、已登录 ChatGPT 一键收发、扩展断开时自动开浏览器
- 轨迹检查器（时间线图标或 `/trajectory`）
- 输入框实时上下文占用百分比
- MCP App 回呼同一服务器
- 内核写出文件更精确归属

### 上游 v1.7.0 Trace & Trust

- 轨迹可导出为独立 HTML
- 窗口标题带项目名（本 fork 显示「天成科研助手 — 项目名」，不是 `wisp science`）
- Gemini / Google AI Mode（`web_agent_*`）
- 回合结束关闭本回合打开的标签
- Motif 可加载本地序列
- Share PNG 表格/KaTeX
- MCP 密钥进 OS keyring，不进 SQLite
- write/edit 防 symlink 逃逸
- Python/R worker 进程树、conda/pixi PATH

### 上游 v1.7.1 Remote Trust

- 飞书所有者绑定；变更类工具强制审批
- 微信回合中 `/approval` `/approve` `/reject` `/stop`
- ACP 终端认证
- 更多模型响应形态下的会话引用
- WSL Python/R 从转换后的项目根启动

## 重要 bugfix 与稳定性

- 合并后把误落入 `crates/wisp-*` 的测试夹具迁回 `superscience-*`
- 把上游新文件里残留的 `wisp_*` crate 引用改回 `superscience_*`（协议字符串 `WISP_*` / `__WISP_*` 未改）
- 窗口标题空项目名时类型不匹配已修
- 对话产物从 `Memo<Vec<Artifact>>` 取值，流式助手消息能继续渲染
- 未加入 `tauri-plugin-updater`；应用内更新仍走 TCTOKEN

## 合并时对本地行为的影响

- **没有覆盖**：登录、品牌、浮层外置、随手一聊、环境准备、技能页/模型卡主路径仍在。
- **有意跟上游**：产品版本号 1.5.0 → 1.7.1；浏览器扩展与轨迹检查器是新能力。
- **部分削弱**：能力卡片 `InstallThenGuided` 现在直接开带 skill 引用的引导对话，不再弹出目录技能安装确认层（文案/类型还在，接线在合并中简化）。需要的话可单独恢复。

## 已知限制

- 本包为本地自签名，不能走 Apple 公证分发。首次安装若被拦截，需在「系统设置 → 隐私与安全性」中允许。
- MCP 密钥改存钥匙串后，旧连接若仍把密钥写在 JSON 里，保存会被拒绝，需在设置里重新填密钥。
- 浏览器能力需要安装/更新配套扩展，并在设置里选共享或工作区会话。
- 设置页仍住在聊天壳里，从首页进设置会先把壳显示出来。
